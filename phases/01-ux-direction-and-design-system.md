# Phase 01 — UX Direction & Design System

## Goal
Establish and implement a coherent mobile-first design system and core page layouts.

## Checklist
- [ ] Senior Frontend & UX Specialist reads `DESIGN.md`.
- [ ] Run the installed `/impeccable` workflow and record actionable findings.
- [ ] Run the installed `/ui-ux-pro-max` workflow and record applicable recommendations.
- [ ] Audit existing UI and retain useful established patterns where appropriate.
- [ ] Define semantic design tokens for color, typography, spacing, radius, elevation, and focus.
- [ ] Establish reusable buttons, fields, dialogs, menus, badges/statuses, list rows, and feedback patterns.
- [ ] Implement responsive app shell and navigation.
- [ ] Define loading, empty, error, permission-denied, and reconnecting patterns.
- [ ] Ensure touch targets, keyboard access, visible focus, and reduced-motion support.
- [ ] Use animation libraries only when justified by the interaction.
- [ ] Review at 360px, 390px, 768px, and 1280px.
- [ ] Re-run `/impeccable` review and address major findings.
- [ ] Capture browser observations/screenshots if tooling is available.
- [ ] Update `DESIGN.md` with final decisions and known design debt.

## Exit gate
Design system is implemented in code, not only described; major audit findings are addressed; responsive and accessibility checks are recorded.
