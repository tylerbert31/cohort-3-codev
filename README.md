## Rules
- Check off tasks only after implementation and verification.
- Keep this documentation current when scope, architecture, schema, or acceptance criteria change.
- Do not claim a task passed without recorded evidence (commands, test results, or browser observations).
- Never expose secrets in source code, logs, screenshots, commits, or documentation.
- Use separate Git worktrees for independent, non-overlapping work that can be integrated safely. Do not create worktrees merely to make the agent count look impressive.
